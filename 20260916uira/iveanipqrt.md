# 那些“传男不传女”的遗传病

> 更新时间：2026-09-16 (UTC+8)

❝
小美夫妇 8 年前生育一男宝，孩子出生时未发现异常，只是学习走路的时间比同龄孩子晚了几个月，考虑到每个孩子的成长轨迹不同，小美并没有特别在意。但在孩子 3 岁左右的时候小美发现孩子走路似乎存在异样：开始是用脚尖走路，经常摔跤，很多时候难以从地板上起来，之后逐渐出现爬楼梯困难，这些情况使得夫妇二人不得不重视起来，连忙就诊。

检查发现孩子体内肌酸肌酶（CK）严重超标，医生详细问诊后考虑孩子可能是一位假肥大肌营养不良（DMD）患者，这是一个引起肌肉发育异常的单基因遗传病。在遗传咨询过程中医生还获取到一个关键信息：孩子舅舅 5-6 岁容易摔跤，7-8 岁瘫痪，智力正常，17-18 岁去世，未查病因。考虑到这个疾病的遗传特征，医生建议小美和孩子一起做个基因检测。

检测结果和医生想的一样：小美和孩子 DMD 基因外显子 46-51 区域都存在大片段缺失，孩子确诊为假性肥大型肌营养不良（DMD），孩子遗传自小美。同时考虑 DMD 的遗传特征，孩子过世的舅舅可能也是一样的疾病，而孩子舅舅的遗传来源可能是孩子的外婆，也就是小美的妈妈。

这下小美疑惑了：孩子遗传了我的问题基因，孩子舅舅可能遗传了我妈妈的问题基因，可是我妈妈和我都正常呀，难道这病传男不传女？
真有“传男不传女”的病吗？
正常来说，每个人都有 46 条染色体，其中女性是 46XX，有 2 条 X 染色体；男性是 46XY，只有 1 条 X 染色体。而有一些像假肥大肌营养不良（DMD）这样的单基因遗传病，它的致病基因就位于 X 染色体上。当女性的 1 条 X 染色体携带者致病基因时，另 1 条 X 染色体一般还可以正常发挥功能，所以一般不会表现出临床症状。而男性，由于只有 1 条 X 染色体，因此该条 X 染色体如果携带致病基因就会直接表现为患者。这样的遗传方式被称为 X 连锁遗传，这个遗传模式表现出来的疾病通常给人们留下“传男不传女”的印象。

小美夫妇还能再生个健康孩子吗？
对于 X 连锁遗传病，正常男性和携带者女性生育的子代中，生育的男孩中 50%完全正常，50%为患者；生育的女孩中 50%正常，50%为和自己母亲一样的携带者，在未来即使和正常的男性婚配，生育中也可能将这个致病基因以和自己母亲一样的模式传递给下一代。

小美就是携带者女性，本人不患病。所以也就是说小美未来是有机会生育一个健康孩子的，但为了避免自然怀孕带来的不确定风险，在医生的指导下，小美选择了三代试管婴儿 PGT-M，计划通过测序技术先对胚胎遗传物质进行分析，挑选健康的囊胚进行移植，从而避免遗传缺陷儿的出生。

治疗：

2022 年中小美开始接受治疗，从前期沟通制定治疗方案到取卵、ICSI 授精整个过程都比较顺利，在行 PGT-M 检测中也挑选到了完全不携带小美的这条异常 X 染色体的囊胚，人工周期后进行了移植并成功妊娠。孕 20 周产前诊断提示胎儿染色体核型+FISH+CNV 均未见明显异常。2023 年 7 月小美足月剖宫产一个健康的男孩。
小编提示：
除了小美家的这种假肥大肌营养不良（DMD）之外，常见的所谓“传男不传女”的 X 连锁遗传病还有血友病、X-连锁鱼鳞病、蚕豆病等。对于有这类疾病家族史的备孕夫妇，建议在孕前通过基因检测明确诊断，必要时通过三代试管阻断致病基因的传递；对于不清楚家族史的备孕夫妇可以通过高精度临床外显携带者筛查提前评估风险。
