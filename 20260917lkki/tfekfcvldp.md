# 【健康科普】带状疱疹病毒引起的急性传染病

> 更新时间：2026-09-17 (UTC+8)

啥？这么吓人？到底谁传染？手上、脸上甚至屁股上都是哪来的东西，密密麻麻的吓死人咋突然就长了这个怪物这个东西是水痘 - 带状疱疹病毒引起的急性传染病得过的人都知道，那种痛，痛不，千万碰不得...患者在发病初期常出现发热、头痛、乏力、食欲减退等全身症状，儿童症状相对较轻，而成人症状往往更严重，还可能并发肺炎、脑炎等严重疾病。别慌，如下预防办法
1. 疫苗接种

接种水痘疫苗是预防水痘最有效、最经济的措施。儿童应在12-15月龄接种第1剂，4- 6岁接种第2剂；未患过水痘且未接种过疫苗的成人，也可根据自身情况接种。
2. 个人卫生

保持良好的个人卫生习惯，勤洗手，避免用手触摸口鼻和眼睛；咳嗽或打喷嚏时，用纸巾、肘部遮掩口鼻。

3. 环境清洁

定期开窗通风，保持室内空气流通；对日常用品如玩具、餐具等进行定期消毒。
4. 避免接触

水痘流行期间，尽量避免前往人员密集的场所，如发现水痘患者，应及时隔离，直至全部皮疹结痂干燥。

得了咋办？也别慌

1.居家隔离

一旦确诊水痘，应立即居家隔离，避免传染给他人，隔离时间一般至皮疹全部结痂干燥，大约需要2 - 3周。
2. 皮肤护理

保持皮肤清洁，勤换内衣，避免搔抓皮疹，以防继发细菌感染，留下疤痕。可在医生指导下使用炉甘石洗剂涂抹止痒。
3. 饮食与休息

饮食宜清淡、易消化，多吃新鲜蔬菜水果，补充维生素，避免食用辛辣、油腻、刺激性食物；保证充足的睡眠和休息，有助于身体恢复。
4. 及时就医

若出现高热不退、头痛剧烈、呼吸困难、呕吐等症状，应立即就医，警惕并发症的发生。

水痘虽然常见，但只要我们了解其特点，做好预防措施，科学护理，就能有效应对。
